Signature framework

The PPPP method

Four visible P's move a problem from history to habit. A hidden fifth P — Protocol — is the synapse that connects and standardizes all of them.

Past Present Possible Practice + Protocol

Protocol is the thread.

Past, Present, Possible and Practice are beads. On their own they scatter. Protocol is the thread they're strung on — the repeatable process that runs through every bead, holds them in order, and standardizes whatever you string onto it. Pull the thread and the whole strand moves together.

It is hidden because it is the line, not the beads — the wiring you stop noticing once it holds.

P1
Evidence

Past

What already happened — history, data, prior art, audits. We start from the record, not a guess. Most failures trace back to skipping this.

// in practice: audit what exists before proposing anything new.

P2
Diagnosis

Present

What is true right now — the live state, the constraints, the reality on the ground today. An honest snapshot before any intervention.

// in practice: map the current system exactly as it runs, not as it's described.

P3
Imagination

Possible

What could be — the option space, the futures worth designing toward. Diverge widely here before converging.

// in practice: generate options against the evidence, then choose deliberately.

P4
Execution

Practice

Repeated, deliberate action that compounds. The part most people skip — and the part an Olympic career makes non-negotiable.

// in practice: ship, measure, repeat — on a cadence, not on a whim.

P5
Integration · hidden

Protocol — the connective fifth P

The thread the other four are strung on. Process/Protocol that standardizes and reinforces anything — running through Past, Present, Possible and Practice so four loose beads become one continuous strand.

// in practice: write the protocol down so the system survives without you in the room.
