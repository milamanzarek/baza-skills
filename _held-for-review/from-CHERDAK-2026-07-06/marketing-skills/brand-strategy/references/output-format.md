# Output Format Conventions

## Markdown Format

### Structure
Use this top-level hierarchy:

```
# [Brand Name] — Brand Positioning Framework
*Generated: [date] | Version 1.0*

---

## Summary Table
| Component | Summary |
|---|---|
| ICP (Primary) | [1-line description] |
| Value Prop | [1-sentence] |
| Core Differentiator | [1 phrase] |
| Positioning Statement | [best option] |
| Brand Voice | [3 words] |

---

## 1. Ideal Customer Profile
...

## 2. Core Value Proposition
...

## 3. Differentiation & Competitive Positioning
...

## 4. Messaging Pillars
...

## 5. Brand Voice & Tone
...

## 6. Tagline / Positioning Statement Options
...

## 7. One-Page Summary
...
```

### Section formatting rules
- Use `###` for sub-sections within each section
- Use `**bold**` for labels (e.g., pillar names, proof points)
- Use bullet lists for enumerated items; prose for narrative explanation
- Use blockquotes (`>`) for example copy / "how this sounds" illustrations
- Use `---` dividers between major sections
- Never pad sections with filler — if a field can't be populated from available inputs, say so explicitly and note what information would unlock it
